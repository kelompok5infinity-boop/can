SISTEM INFORMASI GEREJA AMIN JEMAAT HELEFANIKHA

Isi folder:
- index.html       : Beranda
- jadwal.html      : Jadwal pelayanan
- jemaat.html      : Data jemaat
- kegiatan.html    : Kegiatan gereja
- login.html       : Form tampilan login admin (belum autentikasi sungguhan)
- assets/style.css : Desain, warna, dan foto latar belakang
- assets/app.js    : Pencarian tabel dan interaksi demo
- assets/latar-gereja.jpg : Foto interior gereja yang Anda unggah
- assets/logo-gereja.jpg  : Logo Gereja Amin Jemaat Helefanikha yang Anda unggah

CARA MEMBUKA DI VISUAL STUDIO CODE
1. Ekstrak ZIP.
2. Foto latar belakang dan logo sudah ditempatkan dalam folder assets.
3. Buka folder hasil ekstrak di Visual Studio Code.
4. Jalankan index.html menggunakan ekstensi Live Server atau buka langsung di browser.
5. Pastikan perangkat tersambung internet agar Bootstrap CDN dan Google Fonts dimuat.

PENTING SEBELUM ONLINE
Ini adalah template frontend HTML/CSS/JavaScript. Tautan antarhalaman dan pencarian tabel bekerja, tetapi data yang ada masih contoh statis. Login belum aman dan belum terhubung ke database.
Agar menjadi sistem informasi sungguhan yang dapat mengelola data, tambahkan backend (misalnya PHP), database MySQL, validasi server, session login, pembatasan akses admin, HTTPS, backup, dan perlindungan data pribadi jemaat. Jangan memasukkan data pribadi asli sebelum akses dan keamanannya disiapkan.

Bootstrap stylesheet menggunakan CDN Bootstrap 5.3.8.
